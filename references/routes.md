## Возможности среды, не включённые в архив

OpenAI Docs, документы, PDF, таблицы, презентации, ImageGen, Sites, Supabase и Codex Security выбирать из реального каталога получателя. Их инструменты, подключения и платные права не передаются копированием инструкций. Если подходящий форматный навык доступен — прочитать его. Если отсутствует — обозначить ограничение и предложить доступный путь; не утверждать, что инструмент установлен.

Для OpenAI сначала доступный официальный документационный маршрут. Для безопасности выбрать один процесс по объекту: навыки, приложение, diff или проверка конкретного исправления. Не считать статический анализ навыка аудитом приложения.

Если обязательный дизайн-навык или его данные отсутствуют, не заменять их «встроенным дизайном»: восстановить пакет либо запросить конкретный источник. Отсутствующий внешний сервис не блокирует независимую локальную работу.

Для явно запрошенного ScrapeGraphAI или семантического извлечения из неодинаковых страниц — `scrapegraph-research`. Для устойчивых селекторов — `scrapling-research`; API/коннектор имеет приоритет. Новый маршрут не разрешает установку, внешний LLM или генерируемый код сам по себе.
