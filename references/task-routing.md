# Выбор процесса

Прочитать при первом содержательном задании. Для доставки результата — delivery-workflow.md; для кода/интеграций — coding-delivery.md; для нового визуального направления — design-synthesis.md. Восстановить состояние, определить ожидаемый результат, существенные неизвестные, цену ошибки и фактические инструменты. Если запрос содержит несколько частей, разделить их по результатам, сохранить зависимости и довести каждую разрешённую часть. Не превращать это в анкету на каждый ответ.

| Результат | Процесс | Что доказывает готовность |
|---|---|---|
| Объяснение, термин | Уровень читателя → прямой ответ → пример при необходимости; animation-vocabulary для эффекта | Ответ на вопрос без выдуманных фактов; свежие/сомнительные сведения проверены |
| Код, исправление | Прочитать проектные правила и код → воспроизвести проблему/уточнить контракт → минимальное согласованное изменение → целевые проверки | Наблюдаемое требуемое поведение, уместные тесты и честный перечень непроверенного |
| Архитектура | Ограничения и критерии → варианты с последствиями → выбранное решение → реализация, если запрошена | Решение соответствует реальной среде, проверены критичные зависимости |
| Новый продукт / переосмысление | grilling → product-discovery → concept-development → UI-специалисты и источники → пробы основного сценария → выбор → реализация | Исследование изменило решения; разные механики; проверен законченный опыт и визуал, не только документы |
| Новый интерфейс по готовой концепции | Восстановить концепцию → emil-design-eng + ui-ux-pro-max → источники и варианты → выбор → реализация | Сохранён сценарий, DESIGN содержит основания; просмотр широкого/узкого экрана и состояний |
| Правка интерфейса | Восстановить выбранный дизайн → целевые UI-навыки → точная правка | Сохранены контент и направление; проверено изменённое поведение |
| Иллюстрация | illustration-directions для выбора направления; доступный imagegen для растрового результата | Выбранный стиль, согласованные сюжет/формат, просмотр результата; стиль картинки не заменяет систему интерфейса |
| Исследование | research.md + agent-reach / профильный коннектор → источники → сравнение → вывод | Разделены факт, вывод, неопределённость; ссылки ведут к доказательствам |
| Табличный сбор с сайтов | Коннектор/API при наличии; scrapling-research при необходимости парсинга | Проверены поля, страницы, пропуски, дубли, происхождение и время данных |
| Документ, таблица, презентация, PDF | Навык формата из фактического каталога | Проверен открываемый файл, содержимое и отображение, а не только создание файла |
| Видео VOX | vox-frame-first только для выбранного формата | Согласованный сценарий и визуальное направление; просмотр кадров, звука, титров |
| Безопасность | Один процесс по объекту: приложение, diff, навыки или исправление | Воспроизводимые находки, границы проверки; отсутствие находок не равно гарантии |
| Навыки: создать/исправить/проанализировать | skill-creator при наличии + skill-audit.md; absolute-skill-safety при проверке безопасности пакета | Проверена структура, маршрутизация и реальное поведение; нет выдуманного прохождения проверок |

Все процессы таблицы используют GPT-6.1 Sol по [model-policy.md](model-policy.md): low/medium/high по сложности. Новый тип задачи не является причиной самостоятельно перейти на другую модель. Кратко назвать рекомендацию и причину в начале, повторять только при изменении. Доступность инструмента не означает необходимость его применять. Не создавать агентов, задачи, подключения или подписки ради следования таблице.

В `.absolute/STATE.md` сохранить маршрут, выбранные навыки, рекомендацию модели и фактически известную модель/неизвестность, существенные ограничения и критерий приёмки. Для простого объяснения не создавать служебную папку. Перед продолжением проверять только изменения и нужные зависимости, а не проводить полный аудит заново.

Для явно запрошенного ScrapeGraphAI или семантического извлечения из неодинаковых страниц — `scrapegraph-research`. Для устойчивых селекторов — `scrapling-research`; API/коннектор имеет приоритет. Новый маршрут не разрешает установку, внешний LLM или генерируемый код сам по себе.
