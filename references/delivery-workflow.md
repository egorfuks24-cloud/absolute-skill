# Доставка согласованного результата

Для нового содержательного задания восстановить исходный запрос, цель, тип результата и критерии готовности. Отделить обязательную область от факультативных улучшений. Бриф/приёмка — рабочая опора, не длинная анкета и не новый обязательный JSON.

## Не уменьшать задачу незаметно
Сайт обучения вождению, один учебный сценарий и полный курс — разные результаты. Для сайта выяснить нужные входы, навигацию, контент/функции и основной путь; минимальный демонстратор назвать демонстратором. Выбор симуляционных ответов не разрешает утверждать, что исходный большой запрос выполнен малым фрагментом. Сохранять исходную цель даже когда делаем промежуточную пробу. Ограничения сети/моделей/сроков обозначить до зависимой работы.

## Матрица приёмки
В BRIEF/VERIFICATION кратко связать реальные требования с наблюдаемыми результатами: требование → экран/путь/обработчик/файл → способ проверки → результат/пробел. Для UI включить основной опыт, ошибки и адаптацию; для данных — входные/выходные контракты; для безопасности — границы доверия. Не писать тесты на каждую строку и не придумывать одинаковую матрицу всем проектам.

Нужные документы и служебные записи не являются самим продуктом. На каждом этапе проверить: что сейчас человек может увидеть/использовать? Что ещё обязательно до согласованного результата? Если остаётся необходимая разрешённая работа, продолжать, а не предлагать её сделать потом.

## Порядок
Интервью по неизвестным → решение/пробы там, где нужен выбор → выбранная область → код/интеграция → применимые проверки → сдача. Нет второго разрешения на рутинные шаги. Молчание не выбирает новый дизайн. Продолжать независимую работу, если один существенный выбор ожидается. Публикация не подразумевается локальным предпросмотром.

При серии отказов не наращивать универсальные запреты по каждому примеру. Сопоставить исходную цель, фактические артефакты и причину отказа; исправить нарушенный метод и проверить другое независимое задание. Исторические PASS сохранять как историю, а не объявлять доказательством новой версии.
