# creator1x · Absolute Skill

Личная рабочая сборка для Codex: уточнение задачи, согласование визуального направления, реализация, память проекта и проверка результата.

Это пользовательский навык, не официальный пакет OpenAI. Публикуется копия установленного навыка от 3 октября 2026 года.

## Состав

- `SKILL.md` — основной процесс.
- `references/` — правила и специализированные маршруты.
- `templates/` — шаблоны памяти проекта и контрактов.
- `scripts/` — локальные структурные проверки.
- `agents/openai.yaml` — описание для интерфейса Codex.

## Установка

Скопируйте папку репозитория под именем `absolute-skill` в каталог навыков вашей среды, например `~/.agents/skills/absolute-skill`, затем начните новую сессию Codex. Вызов: `$absolute-skill`.

## Зависимости и границы

В репозиторий входит только папка `absolute-skill`. Другие навыки из `references/routes.md` устанавливаются отдельно; все перечисленные специалисты в эту публикацию не входят. Дизайн-маршруты требуют соответствующих навыков и их данных. Навык не переносит подключения, инструменты, подписки или права доступа и не переключает модель сам по себе.

Проверки структуры не доказывают качество дизайна, поведение модели или безопасность приложения. Политика моделей и тарифов в справочных материалах содержит датированные сведения и требует проверки в среде получателя.
